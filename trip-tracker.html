Setup guide — Google Cloud Console
  1. Go to console.cloud.google.com and create a new project (e.g. Trip Tracker).
  2. In the left menu: APIs & Services → Library → search Google Calendar API → Enable.
  3. APIs & Services → OAuth consent screen → choose External → fill App name & email → Save.
  4. On the consent screen page add scope: https://www.googleapis.com/auth/calendar.readonly
  5. APIs & Services → Credentials → Create Credentials → OAuth client ID
  6. Application type: Web application. Name: anything.
  7. Authorised JavaScript origins: add https://hapmc.github.io
  8. Click Create — copy the Client ID (ends in .apps.googleusercontent.com).
  9. Open this file, find YOUR_GOOGLE_CLIENT_ID and replace it with your Client ID. Save & push to GitHub.
